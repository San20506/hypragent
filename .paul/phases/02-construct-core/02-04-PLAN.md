  <name>Task 1: Implement tools/ocr.py</name>
  <files>tools/ocr.py</files>
  <action>
    Replace all stubs. Use base64→BytesIO→Pillow→pytesseract pipeline to avoid redundant
    temp file writes when capturing from screen.

    **Imports:**
    ```python
    import base64
    import io
    import os
    import subprocess
    import tempfile
    import uuid

    import pytesseract
    from PIL import Image
    ```

    **extract_text_from_image(image_path) → str:**
    ```python
    img = Image.open(image_path)
    return pytesseract.image_to_string(img)
    ```

    **extract_text_fullscreen() → str:**
    - Capture to temp file, OCR, cleanup:
    ```python
    path = os.path.join(tempfile.gettempdir(), f"hypr-ocr-{uuid.uuid4()}.png")
    try:
        result = subprocess.run(["grim", path], capture_output=True, text=True)
        if result.returncode != 0:
            raise RuntimeError(f"grim failed: {result.stderr.strip()}")
        return pytesseract.image_to_string(Image.open(path))
    finally:
        if os.path.exists(path):
            os.remove(path)
    ```

    **extract_text_from_region(x, y, width, height) → str:**
    - Validate dimensions, capture region, OCR, cleanup:
    ```python
    if width <= 0 or height <= 0:
        raise ValueError(f"width and height must be > 0, got {width}x{height}")
    path = os.path.join(tempfile.gettempdir(), f"hypr-ocr-{uuid.uuid4()}.png")
    try:
        result = subprocess.run(
            ["grim", "-g", f"{x},{y} {width}x{height}", path],
            capture_output=True, text=True)
        if result.returncode != 0:
            raise RuntimeError(f"grim failed: {result.stderr.strip()}")
        return pytesseract.image_to_string(Image.open(path))
    finally:
        if os.path.exists(path):
            os.remove(path)
    ```

    **Avoid:**
    - shell=True in any subprocess call
    - Leaving temp files on exception (always use try/finally)
    - Importing screenshot module — duplicate the grim call to keep M3 independent
    - pytesseract.image_to_string on a path string — open with Pillow first for correct format handling
