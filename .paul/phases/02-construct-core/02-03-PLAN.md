<task type="auto">
  <name>Task 1: Implement tools/mouse.py</name>
  <files>tools/mouse.py</files>
  <action>
    Replace all stub functions with real ydotool implementations.

    **Pattern — shared helper at top of module:**
    ```python
    import os
    import subprocess
    import time

    YDOTOOL_SOCKET = "/run/user/1000/.ydotool_socket"

    def _ydotool(*args: str) -> None:
        env = {**os.environ, "YDOTOOL_SOCKET": YDOTOOL_SOCKET}
        result = subprocess.run(["ydotool", *args], capture_output=True, text=True, env=env)
        if result.returncode != 0:
            raise RuntimeError(f"ydotool {args[0]} failed: {result.stderr.strip()}")
    ```

    **move_mouse(x, y) → None:**
    - `_ydotool("mousemove", "--absolute", "-x", str(x), "-y", str(y))`

    **click(x, y, button="left") → None:**
    - Move first: `_ydotool("mousemove", "--absolute", "-x", str(x), "-y", str(y))`
    - Button codes: left=0xC0, right=0xC1, middle=0xC2
    - Map button str → hex code, then: `_ydotool("click", hex(code))`
    - Raise ValueError for unknown button

    **double_click(x, y) → None:**
    - Move to position, then two rapid clicks with 50ms delay:
      ```python
      _ydotool("mousemove", "--absolute", "-x", str(x), "-y", str(y))
      _ydotool("click", "0xC0")
      time.sleep(0.05)
      _ydotool("click", "0xC0")
      ```

    **drag(from_x, from_y, to_x, to_y) → None:**
    - mousedown (0x40 = left button down only), move, mouseup (0x80 = left button up only):
      ```python
      _ydotool("mousemove", "--absolute", "-x", str(from_x), "-y", str(from_y))
      _ydotool("click", "0x40")   # button down, no release
      _ydotool("mousemove", "--absolute", "-x", str(to_x), "-y", str(to_y))
      _ydotool("click", "0x80")   # button up, no press
      ```

    **scroll(x, y, direction, amount) → None:**
    - Move to position first, then scroll:
      ```python
      _ydotool("mousemove", "--absolute", "-x", str(x), "-y", str(y))
      axis_y = -amount if direction == "up" else amount
      _ydotool("scroll", "--axis-x", "0", "--axis-y", str(axis_y))
      ```
    - Raise ValueError if direction not in ("up", "down")

    **Avoid:**
    - shell=True in any subprocess call — security risk
    - Hardcoding YDOTOOL_SOCKET in env without {**os.environ} merge — other env vars needed
    - Setting YDOTOOL_SOCKET globally via os.environ — modifies process env, prefer local dict
  </action>

<task type="auto">
  <name>Task 2: Implement tools/keyboard.py</name>
  <files>tools/keyboard.py</files>
  <action>
    Replace all stub functions with real ydotool implementations.

    **Use same _ydotool helper pattern as mouse.py (duplicate in this module — no shared utility file needed).**

    **type_text(text) → None:**
    - `_ydotool("type", "--delay", "20", "--", text)`
    - `--delay 20` = 20ms between keystrokes (prevents dropped chars under load)
    - `--` separates flags from text (handles text starting with "-")
    - Raise ValueError if text is empty string

    **press_key(key) → None:**
    - Normalize key: replace "+" with "+" for ydotool (ydotool uses "ctrl+c" format natively)
    - `_ydotool("key", key)`
    - Common key names (pass through as-is, ydotool uses X11 keysym names):
      - "Return", "Escape", "Tab", "BackSpace", "Delete"
      - "ctrl+c", "ctrl+v", "ctrl+z", "super+l"
      - "F1" through "F12"

    **hotkey(*keys) → None:**
    - Join with "+" and call press_key:
      ```python
      def hotkey(*keys: str) -> None:
          press_key("+".join(keys))
      ```
    - Raise ValueError if no keys provided

    **Avoid:**
    - ydotool type without `--` — text like "-flag" would be parsed as an option
    - Omitting --delay — fast typing drops chars reliably
    - shell=True in any subprocess call
  </action>

        try:
            amount = arguments.get("amount", 3)
