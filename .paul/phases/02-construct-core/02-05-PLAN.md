    **send_message(self, messages, tools, images) → AgentResponse:**

    Step 1 — Convert MCP tool schemas to Anthropic format (inputSchema → input_schema):
    ```python
    anthropic_tools = [
        {
            "name": t["name"],
            "description": t.get("description", ""),
            "input_schema": t.get("inputSchema", t.get("input_schema", {})),
        }
        for t in tools
    ]
    ```

    Step 2 — Build message list, injecting images into last user message:
    ```python
    api_messages = [
        {"role": m["role"], "content": m["content"]}
        for m in messages
    ]
    if images and api_messages:
        # Inject before the last user message's text content
        last = api_messages[-1]
        text = last["content"] if isinstance(last["content"], str) else ""
        image_blocks = [
            {
                "type": "image",
                "source": {
                    "type": "base64",
                    "media_type": "image/png",
                    "data": img,
                },
            }
            for img in images
        ]
        last["content"] = [*image_blocks, {"type": "text", "text": text}]
    ```

    Step 3 — Call API:
    ```python
    response = self._client.messages.create(
        model=self._model,
        max_tokens=4096,
        tools=anthropic_tools if anthropic_tools else [],
        messages=api_messages,
    )
    ```

    Step 4 — Parse response:
    ```python
    content = ""
    tool_calls: list[dict] = []
    for block in response.content:
        if block.type == "text":
            content = block.text
        elif block.type == "tool_use":
            tool_calls.append({
                "name": block.name,
                "input": block.input,
                "id": block.id,
            })
    return AgentResponse(
        content=content,
        tool_calls=tool_calls,
        stop_reason=response.stop_reason or "end_turn",
    )
    ```

    **Avoid:**
    - Catching API exceptions here — let them propagate to AgentLoop (M6)
    - Storing api_key on self — only the client needs it
    - Mutating the input messages list — build api_messages as a new list
    - tools=[] when tools is empty — pass empty list, not None (API rejects None)
