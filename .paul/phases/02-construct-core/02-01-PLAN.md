<task type="auto">
  <name>Task 1: Install system packages and configure uinput + ydotoold</name>
  <files>install-deps.sh</files>
  <action>
    Run system package installation:
    ```
    sudo pacman -S --needed grim slurp ydotool wl-clipboard tesseract tesseract-data-eng
    ```

    Enable uinput kernel module now and on boot:
    ```
    sudo modprobe uinput
    echo "uinput" | sudo tee /etc/modules-load.d/uinput.conf
    ```

    Add current user to input group (for ydotool socket access):
    ```
    sudo usermod -aG input $USER
    ```
    Note: Group change requires re-login to take effect. If ydotool fails with permission error
    after this step, newgrp input or re-login is required.

    Enable and start ydotoold as a systemd user service:
    ```
    systemctl --user enable --now ydotoold
    ```

    Create install-deps.sh documenting all steps taken (for future install.sh):
    ```bash
    #!/usr/bin/env bash
    # HyprAgent system dependency installer (CachyOS/Arch)
    set -euo pipefail
    sudo pacman -S --needed grim slurp ydotool wl-clipboard tesseract tesseract-data-eng
    sudo modprobe uinput
    echo "uinput" | sudo tee /etc/modules-load.d/uinput.conf
    sudo usermod -aG input "$USER"
    systemctl --user enable --now ydotoold
    uv sync
    uv run playwright install chromium
    echo "Done. Re-login required for input group membership to take effect."
    ```
    chmod +x install-deps.sh

    Avoid: Installing system packages via pip/uv — system tools must be pacman packages.
  </action>
  <verify>grim --help 2>&1 | head -1 && ydotool --help 2>&1 | head -1 && wl-copy --version 2>&1 | head -1 && tesseract --version 2>&1 | head -1 && lsmod | grep uinput && systemctl --user is-active ydotoold</verify>
  <done>AC-1 and AC-2 satisfied: all tools callable, uinput loaded, ydotoold active</done>
