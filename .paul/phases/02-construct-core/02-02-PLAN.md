    Replace all 3 stub functions with real implementations using `grim` subprocess.

    **capture_fullscreen() → str:**
    - Write to a temp file: `grim /tmp/hypr-screenshot-{uuid4()}.png`
    - Read the file as bytes, base64-encode, return as str
    - Delete the temp file after encoding
    - Use subprocess.run with list args (no shell=True)
    - Raise RuntimeError if grim exits non-zero

    **capture_region(x, y, width, height) → str:**
    - Use: `grim -g "{x},{y} {width}x{height}" /tmp/hypr-screenshot-{uuid4()}.png`
    - Same encode-and-delete pattern as capture_fullscreen
    - Validate width > 0 and height > 0 before calling grim

    **save_screenshot(path: str) → None:**
    - Use: `grim {path}` (grim writes PNG directly)
    - No temp file needed — grim writes to path directly
    - Raise RuntimeError if grim exits non-zero

    **Imports needed:** subprocess, base64, uuid, os, pathlib.Path

    **Avoid:**
    - shell=True in subprocess calls — security risk
    - Leaving temp files on error — use try/finally cleanup
    - Hardcoding /tmp — use tempfile.mktemp() or uuid-based path
    - Pillow for encoding — grim already outputs PNG; base64.b64encode(bytes) is sufficient
