<objective>
## Goal
Create `agent/device_manager.py` with a `DeviceManager` singleton that creates two persistent UInput virtual devices (HyprAgent Keyboard + HyprAgent Mouse) at MCP server startup and destroys them at shutdown.

## Purpose
This is the foundation of SPEC-002. The tool rewrites in 06-02 depend on `DeviceManager` existing and being importable. Without this layer, `tools/mouse.py` and `tools/keyboard.py` have nothing to write events to.

- Modified: `mcp_server.py` — lifespan hook calling `devices.start()` / `devices.stop()`
- Modified: `config.yaml.example` — `tools.mouse.screen_width/height` and keyboard config
- Modified: `pyproject.toml` — replace `ydotool` dependency note with `evdev` package
</objective>

  <name>Task 1: Create agent/device_manager.py</name>
  <files>agent/device_manager.py</files>
  <action>
    Create new file implementing DeviceManager per SPEC-002 §4.

    KB_CAPABILITIES: EV_KEY with range(KEY_ESC, KEY_MICMUTE + 1) plus explicit modifier keys.
    MOUSE_CAPABILITIES: EV_KEY (BTN_LEFT/RIGHT/MIDDLE), EV_ABS (ABS_X, ABS_Y with AbsInfo
    from config), EV_REL (REL_WHEEL), EV_SYN (SYN_REPORT).
    Mouse UInput must include input_props=[e.INPUT_PROP_DIRECT] — required for Wayland ABS
    acceptance (without it Hyprland ignores EV_ABS events).

    DeviceManager class:
    - __init__: sets keyboard=None, mouse=None, _started=False
    - start(config): reads screen_width/height from config.tools.mouse; creates both UInput
      devices; logs device paths via print(); sets _started=True
    - stop(): calls keyboard.close() and mouse.close() if _started; sets _started=False
    - verify(): returns dict with keyboard/mouse name, fd, device_node

    Module-level singleton: `devices = DeviceManager()`

    Import guard: if evdev not available, raise ImportError with clear install instructions.

    Vendor/product IDs per spec: KB=(0x4841, 0x4B42), Mouse=(0x4841, 0x4D53).

    Avoid: instantiating UInput at module import time — defer to start().
    Avoid: storing screen resolution as module-level constants — read from config at start().
  </action>
  <verify>
    python3 -c "from agent.device_manager import DeviceManager, devices; print('import ok')"
  </verify>
  <done>AC-1 and AC-2 satisfied: DeviceManager importable; start() creates named UInput devices</done>
</task>

<task type="auto">
  <name>Task 2: Add lifespan hook to mcp_server.py</name>
  <files>mcp_server.py</files>
  <action>
    Modify the _run() coroutine to call devices.start(config) before entering stdio_server
    and devices.stop() in a finally block after stdio_server exits.

    Current _run():
    ```python
    async def _run() -> None:
        async with stdio_server() as (read_stream, write_stream):
            await server.run(read_stream, write_stream, server.create_initialization_options())
    ```

    New _run():
    ```python
    async def _run() -> None:
        cfg = load_config()   # existing config loader or import from agent/config
        devices.start(cfg)
        try:
            async with stdio_server() as (read_stream, write_stream):
                await server.run(read_stream, write_stream, server.create_initialization_options())
        finally:
            devices.stop()
    ```

    Add import: `from agent.device_manager import devices`
    Add import: whatever config loader already exists (check existing imports in mcp_server.py).

    If no config loader exists yet in the import chain, pass a minimal config object with
    tools.mouse.screen_width=2560 and tools.mouse.screen_height=1440 as defaults — mark
    with TODO comment to wire real config later (06-02 can finalize this).

    Avoid: changing any tool handler logic — only touch _run() and imports.
  </action>
  <verify>
    python3 -c "import mcp_server; print('import ok')"
    grep -n "devices.start\|devices.stop" mcp_server.py
  </verify>
  <done>AC-3 satisfied: lifespan hook present and devices singleton imported</done>
