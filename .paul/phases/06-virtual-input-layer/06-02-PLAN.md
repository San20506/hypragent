<task type="auto">
  <name>Task 1: Rewrite tools/mouse.py using DeviceManager</name>
  <files>tools/mouse.py</files>
  <action>
    Full rewrite per SPEC-002 §5. Keep all existing function signatures unchanged
    (move_mouse, click, double_click, drag, scroll) — MCP tool handlers depend on these.

    Imports: `from evdev import ecodes as e` and `from agent.device_manager import devices`
    Remove: all `subprocess`, `socket`, `struct`, `os` imports and `_ydotool()` helper,
    `YDOTOOL_SOCKET` constant, `_BUTTON_CODES` dict.

    **move_mouse(x, y):**
    ```
    devices.mouse.write(e.EV_ABS, e.ABS_X, x)
    devices.mouse.write(e.EV_ABS, e.ABS_Y, y)
    devices.mouse.syn()
    ```

    **click(x, y, button="left"):**
    ```
    move_mouse(x, y)
    btn = _resolve_button(button)
    devices.mouse.write(e.EV_KEY, btn, 1)   # down
    devices.mouse.syn()
    devices.mouse.write(e.EV_KEY, btn, 0)   # up
    devices.mouse.syn()
    ```

    **double_click(x, y):**
    ```
    click(x, y)
    time.sleep(0.05)
    click(x, y)
    ```
    Remove `button` param — original double_click had no button param.

    **drag(from_x, from_y, to_x, to_y):**
    ```
    move_mouse(from_x, from_y)
    devices.mouse.write(e.EV_KEY, e.BTN_LEFT, 1); devices.mouse.syn()
    steps = max(abs(to_x - from_x), abs(to_y - from_y)) // 10 or 1
    for i in range(1, steps + 1):
        ix = from_x + (to_x - from_x) * i // steps
        iy = from_y + (to_y - from_y) * i // steps
        move_mouse(ix, iy)
        time.sleep(0.005)
    devices.mouse.write(e.EV_KEY, e.BTN_LEFT, 0); devices.mouse.syn()
    ```

    **scroll(x, y, direction, amount):**
    Keep the `x, y, direction, amount` signature (matches existing MCP handler).
    Move to position first, then:
    ```
    value = 1 if direction == "up" else -1
    for _ in range(amount):
        devices.mouse.write(e.EV_REL, e.REL_WHEEL, value)
        devices.mouse.syn()
        time.sleep(0.02)
    ```

    **_resolve_button:**
    ```python
    _BUTTON_MAP = {"left": e.BTN_LEFT, "right": e.BTN_RIGHT, "middle": e.BTN_MIDDLE}
    def _resolve_button(name: str) -> int:
        if name not in _BUTTON_MAP:
            raise ValueError(f"Unknown button: {name!r}. Use: left, right, middle")
        return _BUTTON_MAP[name]
    ```

    Module docstring: update to describe evdev/UInput, remove ydotool references.

    Avoid: changing function signatures — MCP handlers call these by positional args.
    Avoid: importing time at module level if not already there — add only what's needed.
  </action>

  </verify>

<task type="auto">
  <name>Task 2: Rewrite tools/keyboard.py using DeviceManager + static keymap</name>
  <files>tools/keyboard.py</files>
  <action>
    Full rewrite per SPEC-002 §6. Keep existing function signatures: type_text(text),
    press_key(key), hotkey(*keys).

    Imports: `from evdev import ecodes as e`, `from agent.device_manager import devices`,
    `import subprocess`, `import time`.
    Remove: `os`, `YDOTOOL_SOCKET`, `_ydotool()`.

    **Static ASCII keymap** — `KEYMAP: dict[str, tuple[int, bool]]`
    Maps char → (keycode, needs_shift). Build a comprehensive map covering:
    - a-z: KEY_A through KEY_Z, shift=False
    - A-Z: KEY_A through KEY_Z, shift=True
    - 0-9: KEY_0 through KEY_9, shift=False
    - Space: KEY_SPACE, False
    - Return/newline (\n): KEY_ENTER, False
    - Tab (\t): KEY_TAB, False
    - Common symbols with shift=False: ` - = [ ] \ ; ' , . /
      mapped to: KEY_GRAVE, KEY_MINUS, KEY_EQUAL, KEY_LEFTBRACE,
      KEY_RIGHTBRACE, KEY_BACKSLASH, KEY_SEMICOLON, KEY_APOSTROPHE,
      KEY_COMMA, KEY_DOT, KEY_SLASH
    - Common symbols with shift=True (US layout):
      ! @ # $ % ^ & * ( ) _ + { } | : " < > ? ~
      mapped to shift+1, shift+2, shift+3, shift+4, shift+5,
      shift+6, shift+7, shift+8, shift+9, shift+0, shift+minus,
      shift+equal, shift+leftbrace, shift+rightbrace, shift+backslash,
      shift+semicolon, shift+apostrophe, shift+comma, shift+dot,
      shift+slash, shift+grave

    **type_text(text):**
    ```
    for char in text:
        entry = KEYMAP.get(char)
        if entry is None:
            _paste_via_clipboard(char)
            continue
        keycode, needs_shift = entry
        if needs_shift:
            _press_key_raw(e.KEY_LEFTSHIFT, hold=True)
        _press_key_raw(keycode)
        if needs_shift:
            _press_key_raw(e.KEY_LEFTSHIFT, hold=False)
        time.sleep(0.012)  # 12ms per SPEC-002 §4 keyboard config default
    ```

    **press_key(key):** Parse "ctrl+shift+t" style strings:
    ```
    parts = [p.strip().lower() for p in key.split("+")]
    modifiers, main_key = parts[:-1], parts[-1]
    mod_codes = [_resolve_modifier(m) for m in modifiers]
    key_code = _resolve_key(main_key)
    for mod in mod_codes:
        devices.keyboard.write(e.EV_KEY, mod, 1)
    devices.keyboard.write(e.EV_KEY, key_code, 1)
    devices.keyboard.syn()
    devices.keyboard.write(e.EV_KEY, key_code, 0)
    for mod in reversed(mod_codes):
        devices.keyboard.write(e.EV_KEY, mod, 0)
    devices.keyboard.syn()
    ```

    **hotkey(*keys):** Keep existing behavior — join and call press_key:
    ```
    if not keys:
        raise ValueError("at least one key required")
    press_key("+".join(keys))
    ```

    **_press_key_raw(keycode, hold=None):**
    - hold=True: write value=1, syn
    - hold=False: write value=0, syn
    - hold=None: write value=1, syn, write value=0, syn

    **_resolve_modifier:** ctrl→KEY_LEFTCTRL, shift→KEY_LEFTSHIFT,
    alt→KEY_LEFTALT, super/meta→KEY_LEFTMETA

    **_resolve_key(name):** Try `getattr(e, f"KEY_{name.upper()}", None)`;
    if None and name starts with "f" and rest is digits → KEY_F{N};
    else raise ValueError.

    **_paste_via_clipboard(char):**
    ```
    subprocess.run(["wl-copy", char], check=True)
    time.sleep(0.02)
    press_key("ctrl+v")
    time.sleep(0.02)
    ```

    Module docstring: update to describe evdev/UInput, remove ydotool references.

    Avoid: changing type_text/press_key/hotkey signatures.
    Avoid: using subprocess for normal key injection — only for clipboard fallback.
  </action>
  <verify>

    grep -c "ydotool\|YDOTOOL_SOCKET" tools/keyboard.py || echo "0 matches — clean"
