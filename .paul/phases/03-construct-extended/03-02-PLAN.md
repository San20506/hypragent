<task type="auto">
  <name>Task 1: Implement tools/browser.py</name>
  <files>tools/browser.py</files>
  <action>
    Replace stubs. Use a module-level Playwright singleton so the browser persists across
    multiple tool calls in an agent session.

    **Imports:**
    ```python
    import base64
    from playwright.sync_api import sync_playwright, Playwright, Browser, Page
    ```

    **Module-level singleton state:**
    ```python
    _playwright_ctx: Playwright | None = None
    _browser: Browser | None = None
    _page: Page | None = None
    ```

    **_ensure_browser() → Page (private helper):**
    ```python
    def _ensure_browser() -> Page:
        global _playwright_ctx, _browser, _page
        if _page is None:
            _playwright_ctx = sync_playwright().start()
            _browser = _playwright_ctx.chromium.launch(
                headless=False,
                args=["--ozone-platform=wayland"],
            )
            _page = _browser.new_page()
        return _page
    ```

    **browser_open(url) → None:**
    ```python
    page = _ensure_browser()
    page.goto(url, wait_until="domcontentloaded")
    ```

    **browser_navigate(url) → None:**
    ```python
    page = _ensure_browser()
    page.goto(url, wait_until="domcontentloaded")
    ```
    (same as browser_open — browser_open initializes if needed, navigate reuses it)

    **browser_click(selector) → None:**
    ```python
    _ensure_browser().click(selector)
    ```

    **browser_type(selector, text) → None:**
    ```python
    _ensure_browser().fill(selector, text)
    ```

    **browser_scroll(direction, amount) → None:**
    ```python
    if direction not in ("up", "down"):
        raise ValueError(f"Unknown direction: {direction!r}")
    delta = -amount if direction == "up" else amount
    _ensure_browser().evaluate(f"window.scrollBy(0, {delta})")
    ```

    **browser_screenshot() → str:**
    ```python
    raw = _ensure_browser().screenshot(type="png")
    return base64.b64encode(raw).decode("ascii")
    ```

    **browser_get_text(selector) → str:**
    ```python
    return _ensure_browser().inner_text(selector)
    ```

    **browser_close() → None:**
    ```python
    global _playwright_ctx, _browser, _page
    if _browser is not None:
        _browser.close()
        _browser = None
        _page = None
    if _playwright_ctx is not None:
        _playwright_ctx.stop()
        _playwright_ctx = None
    ```

    **Avoid:**
    - `async_playwright` — the MCP server is sync at the tool level; sync_playwright is correct
    - `headless=True` — desktop automation agent needs visible browser
    - Missing `--ozone-platform=wayland` — required for Chromium on Wayland
    - Catching Playwright exceptions in the tool — let them propagate to MCP handler
    - `wait_until="networkidle"` — too slow; "domcontentloaded" is sufficient
