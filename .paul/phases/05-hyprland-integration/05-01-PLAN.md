  <action>
    Create `tools/hyprland.py`. All functions run `hyprctl` as a subprocess.
    Use `subprocess.run(["hyprctl", ...], capture_output=True, text=True)`.
    Check `returncode != 0` → raise RuntimeError with stderr.
    Parse JSON with `json.loads(result.stdout)`.

    **Key field mapping** (hyprctl uses camelCase, return snake_case dicts):

    ```python
    def workspace_list() -> list[dict]:
        """Returns all workspaces. Each dict: id, name, windows, monitor, active (bool)."""
        # hyprctl workspaces -j
        # raw keys: id, name, windows, monitorID, hasfullscreen etc.
        # Also call hyprctl activeworkspace -j to get active id, set active=True on match

    def workspace_switch(target: str | int) -> None:
        """Switch to workspace. target: int id, "+1", "-1", "previous", or name."""
        # hyprctl dispatch workspace {target}
        # returncode != 0 → raise RuntimeError

    def clients() -> list[dict]:
        """All open windows. Each dict: address, class_, title, pid,
           workspace_id, workspace_name, x, y, width, height, floating, fullscreen."""
        # hyprctl clients -j
        # raw: address, class (→ class_), title, pid,
        #      workspace.id (→ workspace_id), workspace.name (→ workspace_name),
        #      at[0]/at[1] (→ x, y), size[0]/size[1] (→ width, height),
        #      floating, fullscreen (bool)
        # Note: use class_ to avoid shadowing Python builtin

    def active_window() -> dict | None:
        """Currently focused window. Returns None if no window focused."""
        # hyprctl activewindow -j
        # Returns {"message": "Invalid"} or empty when no window — return None
        # Keys: address, class_, title, workspace_id, workspace_name

    def focus_window(target: str) -> None:
        """Focus window by class or address.
           target: "class:firefox", "address:0x...", or just "firefox"
        """
        # hyprctl dispatch focuswindow {target}
        # If target has no prefix and no ":" → prepend "class:"
        # returncode != 0 → raise RuntimeError
    ```

    **Error handling:**
    - `HYPRLAND_INSTANCE_SIGNATURE` not set → raise `RuntimeError("Not running under Hyprland")`
    - Check env var at top of each function (or shared helper `_check_hyprland()`)
    - `hyprctl` not found (FileNotFoundError) → re-raise with helpful message

    **No new imports beyond stdlib** — `json`, `os`, `subprocess` only.
